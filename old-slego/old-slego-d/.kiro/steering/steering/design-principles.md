# Design Principles

## Style Guidelines

- **ENGLISH**: All code and all .md files are in English
- **Minimalism**: Always prioritize simplicity and clarity
- **Clean CSS**: All CSS is declared near the components that use it.
- **Clear Interface**: Generous spacing, readable typography, consistent colors
- **Responsive**: Ensure interface works on mobile and desktop
- **CSS Classes**: Use CSS classes, not inline styles. Only use inline styles for dynamic values like variables.

## Code Guidelines

- **No Duplication**: Systematically remove repetitions in CSS or code
- **prefer shorter code**: Do not add unnecessary plumbing. Ask before adding architecture mechanisms.
